# 04-chatbot-ui

带 Web UI 界面的聊天机器人

# 技术栈

- Express：SSE 服务端实现（GET/POST）
- LangChain：使用 TS 版本
- React：Vite、SSE 客户端实现（GET/POST）
- TailwindCSS
- shadcn

```bash
API_KEY=sk-xxx
```

# 运行项目

在此目录下，执行以下命令：

```bash
npm install

# 同时启动前后端
npm run dev

# 或是分别启动前后端
npm run dev:ui
npm run dev:server
```
